# 小石头俱乐部 · Water Fly

一个温暖、俏皮的 2D 像素打水漂游戏。原生 Canvas + JavaScript，无构建依赖。

## v1.1 声音与设置

正式默认组合已选定为 **B「口袋像素」动作音效 + 3「漂浮梦境」背景音乐**。第一次载入此版本时，旧试听设置会一次性切换到该组合，音量、静音、画面设置和收藏保持原值；之后仍可自由改选并保存。

游戏右上角齿轮 / Esc 打开设置。提供三套原创合成音效（河岸手作、口袋像素、奇妙实验室）和三种原创循环配乐（午后河岸、像素远足、漂浮梦境），两类可以独立选择。`audio-lab.html` 是独立试听室，包含六段 WAV 小样，选择会同步到同源游戏。

五张地图分别使用不同变调、和声顺序、节奏与环境层。脚步、拾取、蓄力、投掷、连漂、落水、NPC、八类加工和新纪录接入相应音效；投掷时背景音乐自动降低，换图时声音淡入淡出。音频由本项目的振荡器、包络和滤波噪声合成，没有使用外部录音或现成歌曲。小样为音色方向版本，不是录音棚母带。

设置包括总音量、音乐、动作音效、环境声、全部静音、后台静音、减少装饰动画、轨迹显示、操作提示、30/60 FPS、全屏和按住/两次点击投掷。设置单独保存，不改动收藏存档。旧玩家静音状态会保留；首次播放需要点击游戏或按键来解锁浏览器音频。快捷键 M 静音，Esc 暂停/返回。

运行 `npm run audio:render` 可以用同一声音合成器重新导出试听 WAV。游戏中的实时音频不依赖下载这些 WAV；它们只用于独立试听与分享。

## 运行

```sh
git clone https://github.com/guhz18/water-fly.git
cd water-fly
npm start
```

在这个目录执行 `npm start`，打开 http://127.0.0.1:4173 。需要 Node.js 18 或更新版本。不需要 npm install。

Windows 用户也可以双击仓库根目录的 `开始游戏.cmd`。游戏文件在 `dist/`，可以部署到任意静态托管服务。ES Modules 和 Web Workers 需要通过 HTTP 打开，不能直接双击 index.html。

## 玩法

- WASD / 方向键散步，E 拾取或交谈；鼠标或触屏点地面行走，点石头自动靠近拾取。
- 点击口袋里的石头，选「带它去水漂」。调节出手方向、石片倾角、自旋，再按住投掷按钮或空格蓄力，松手出发。
- 5 个场景有不同波浪、风、流速和掉落池；24 种物品包括石片、吐司、键帽、软盘、CPU、鸭子和会说话的石头 NPC。
- 8 个设施可免费砸石、粗磨、减材精加工、优化入水倾角、观测随机量子态、杂交和四位碱基对编辑、改变形成历史，或并行筛选 192 个材料候选。
- 投掷会归还石头。拾取和投掷获得灵感，用于改造。灵感是游戏内资源，无付费功能。
- 自动存档在浏览器 localStorage；水漂手册支持导出和导入 JSON 备份。存档不会跨浏览器同步。

## 物理及边界

`dist/physics.js` 使用 SI 单位，固定 1/240 s 主步长、1/960 s 石体接触积分子步。

- 一维小振幅线性浅水模型：512 网格，dx=0.35 m，水深 1.2 m，交错水位/流速网格、阻尼与边缘吸收。
- 连续计算入水深度、近似湿润面积与动压相关升力/阻力，另外计算重力、空气阻力、浮力、自旋衰减和姿态扰动。
- 从接触状态向上离水才记一次弹跳；不会按照预设数量播放弹跳动画。
- 系数、材质与摆动是经过游戏调校的降阶模型。不是工程 CFD；不解析三维湍流、破波、毛细波或真实量子/生物材料行为。屏幕竖直比例有所夸大。
- 未来材料实验室使用两个 Web Workers 对 192 个候选进行同一物理模型模拟。只在有限网格和固定工况下选优，不是全局材料最优解。

参考：Clanet, Hersen & Bocquet, “Secrets of successful stone-skipping”, Nature 427, 29 (2004), https://www.nature.com/articles/427029a 。Bocquet, “The physics of stone skipping”, https://arxiv.org/abs/physics/0210015 。

## 验证

`npm test`：覆盖 24 种材料 × 5 张地图、姿态敏感性、帧率无关性、水面稳定性、真实离水计数、极端出手条件，以及音效/乐曲信号、循环接缝、WAV 编码和设置参数校验。

## 结构

- `dist/game.js`：探索、输入、收藏、存档、对话、设施、结果界面。
- `dist/art.js`：程序化像素场景与角色/物品精灵。
- `dist/data.js`：地图、物品和设施数据。
- `dist/physics.js`：水面与石头运动求解器。
- `dist/optimizer.js`：并行材料筛选 Worker。
- `dist/sw.js`：本地资源缓存，首次成功访问后支持离线使用。
- `server.mjs`：只监听本机的轻量静态预览服务。
- `dist/synthesis.js`：原创音效、配乐、环境音的纯 PCM 合成器。
- `dist/audio-engine.js`：Web Audio 分轨、音量、淡化与播放管理。
- `dist/settings.js`：游戏设置页与独立设置存储。
- `dist/audio-lab.html`：音效与配乐的独立试听室。
